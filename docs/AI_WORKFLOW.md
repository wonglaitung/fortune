## 1. 提问

### 1.1 前置三问（答不出就不开跑）

> **验证之前，先验证「被验证的对象」。**

| # | 问题 | 判定式 | 本项目实证 |
|---|---|---|---|
| 1 | **数据非空？** | `len(x) > 0`、行数符合预期、唯一值 > 1 | 曾据 `top_features` **全为空数组**断言「港股无绝对价格问题」——**连续两次基于空数据下结论** |
| 2 | **分母是什么？** | `n_eff` / 折数 / 样本区间 / 是否单年独撑 | A股 `净IR 2.15 / PBO 0.17 / DSR 1.000` 三闸全过，但仅 **19 折**、2025 占 **63.6%** → **不升配**（三.45） |
| 3 | **本次改动连带改变了什么？** | 列出全部连带变量 | 2026-10-04 **三次实验**因连带变量不纯全部无法归因 |

> **阈值判据不编码样本量**：「净IR≥0.7 ∧ PBO<0.5 ∧ DSR≥0.95」回答的是
> 「在这个样本上表现如何」，**不回答「这个样本够不够」**——两者必须**分开过闸**。
>
> **空数据不能证伪任何命题**：`len==0` 时"没看见"不等于"不存在"。

### 1.2 诊断型 Prompt 优于猜测型

不要猜"是不是这里错了"，要让它把运行状态呈现出来：

> "请在关键节点加入日志，输出中间过程的数据形态。运行后我把日志发给你，
> 请分析哪一步的数据转换与预想不符。"

**与奥卡姆剃刀的关系**：加日志是诊断期的**临时探针**，定位后即移除——
保持交付物精简 ≠ 拒绝临时诊断手段。

### 1.3 提问技巧不是核心竞争力

> **非专家的核心竞争力不是提问技巧，是「知道该验证什么」**——
> 而"该验证什么"是**过程性知识**（易学），不是**领域性知识**（难学）。
> 本项目拦截过的问题（旧值残留、守卫装错位置、实验变量不纯、门槛源被污染）
> **均无需量化知识即可发现**。
> —— [REVIEW_GATES.md](REVIEW_GATES.md)

## 2. 验证

### 2.1 判读顺序（不可颠倒）

```
① 绝对值异常（准确率 / IC / 概率饱和 / 分组符号一致性）
        ↓
② PBO < 0.5
        ↓
③ DSR ≥ 0.95
        ↓
④ 净IR CI 不跨 0   且   lift > 0
        ↓
⑤ 才谈仓位
```

**执行**（仓库根目录下）：

```bash
python3 scripts/presentation_gate.py --input <csv> --horizon N
```

—— **非零退出即阻断**，不靠"记得跑"。

**为什么顺序不可颠倒**：`PBO/DSR` 实测**检测不出泄漏**——泄漏版
`PBO 0.43 / DSR 1.000` 三闸全过却是假信号（三.28）。第 ① 级最便宜，必须先走。

**第 ① 级三条硬检查**：

1. `Predict_Prob` 是否饱和成 0/1
2. 预测 UP 组 `Relative_Return`（= Actual_Return − HSI 未来收益，CSV 无此列须重建）
   **最大值 ≤ 0 = 符号退化** —— 合法数据实测 **+0.42**，泄漏版 **−1e-05**，**方向勿抄反**
3. 分组符号一致性

### 2.2 显著性必须按 Fold 聚类

行级统计**忽略折间与横截面相关**（同折共享模型、同日多股共享同一未来收益），
有效独立观测 ≈ **折数**，不是行数。

实测：行级 `z = 6.3` → Fold 聚类 `t = 1.40`，**`p = 0.167` 不显著**（三.29）。

> 任何命中率 / 准确率 / lift 的显著性**必须聚类后检验**；
> **行级统计不得用于因果推断**（硬约束 1）。

### 2.3 三种验证手段

| 级别 | 手段 | 要求 |
|---|---|---|
| **最强** | **可执行验证**：本地运行 + 单测 + 黄金数据比对 | 必须。散文规则会漏，脚本不会 |
| **中等** | **多源交叉**：标注来源与推导，独立检索核对 | 必须。**不得让 AI 给自己背书**——AGENTS:115 即复述失真（三.47） |
| **最弱** | **反向质询**：「指出你最可能出错的三处」 | **仅作排查，不可作唯一依据**——约束 1/2 的失职复盘写着「**清单第 1/5 项本该拦住我，两条都没执行**」 |

> 三者都只回答「**算得对不对**」，不回答「**命题成不成立**」。
> 命题由 §1.1 前置三问与 §2.1 判读顺序负责。
>
> **可执行验证必须脚本化**：散文清单靠"记得执行"，脚本靠非零退出——
> A 闸从散文改为 `presentation_gate.py` 即因此。

### 2.4 复现口径（回测特有）

- **同机同代码双跑必须 bit 级一致**，不复现即 bug（`WF_X_DETAIL=1` 列指纹定位）
- **同缓存双跑是伪验收**——只测读取层，测不到计算层（三.42）
- **跨日/跨机只比 lift / 护栏等决策指标**，禁逐行 diff CSV
  （`us_market_data` 仅当天有效，跨日净IR 实测 0.34 / 0.42、PBO 0.41 / 0.64）
- **禁止取最好的一次当结论**——多跑几次总能撞到三门槛全过

## 3. 纠偏

> 缺乏直觉时，凭感觉调整必然滑向碰运气。以下四条是**强制动作**，不是建议。

### 3.1 假设-演绎法：最小可复现

不改全局代码。要求产出**独立最小测试**（输入 → 输出），只验证一个子模块。

### 3.2 第一性原理：降维问数据流

> "抛开框架，这个任务最底层的数据流是怎样的？输入经过哪几步变换得到输出？"

### 3.3 隔离变量：先写连带影响清单

> **跑任何实验前，先写「本次改动会连带改变哪些东西」。**
> 答不出 = 尚未理解该改动，**不该开跑**。

本项目三次实验全部栽在同一处（2026-10-04）：

| 改动 | 以为只改了 | 实际连带改了 |
|---|---|---|
| `--train-window 36→12` | 训练窗 | **测试期也变长**（50→74 折） |
| 剔除 2 个特征 | 特征集 | **绝对值排除列表 40→42**（同文件另一处） |
| 加门控守卫 | 门控 | **特征缓存全量重算**（缓存键含数据末日） |

> **固定随机种子不足以隔离变量。** 本项目的非确定性主要在**管线**：
> sklearn 同分按**列序**取舍（实测选中集合对称差 **22** → 修复后 **0**，见三.48）、
> `set(range(N))` 迭代序、缓存非原子写、模型非确定参数。
>
> **唯一有效验收是同配置双跑 md5 bit 级一致。**

### 3.4 预注册判据 > 让 AI 复述需求

"先总结你的理解"只能防跑偏，**防不了事后找解释**。

> **在看到结果之前，把"什么算成功 / 什么算失败"写成数字或区间。**

实例（2026-10-04 涨跌停实验）：预注册「净IR 降幅 >30% = 依赖 / 30~10% = 部分 /
<10% = 非依赖」→ 实测 −7.3% 干净落入"非依赖"。
若无预注册，很容易在看到「剔除强特征后几乎不变」时自行解释成
"说明还有其他机制在起作用"。

> **预注册的价值不在于猜对，在于让猜错可判定、让事后解释无法冒充结论。**

### 3.5 无直觉纠偏流程

**Step 1 — 建立客观参照物**

- 报错日志：完整复制，作为客观事实
- **黄金数据集**：一小份人工校验无误的 输入 → 预期输出
- 官方规范 / 已入库产物的可复算指纹

**Step 2 — 诊断型 Prompt**（见 §1.2）

**Step 3 — 对抗诊断**

> "请扮演极其严苛的审核者，找出这个方案的 3 个潜在隐患或边界漏洞。"

> **不能作为唯一依据**（§2.3 最弱级）。必须**落成非零退出的脚本**或
> **可 grep 的清单**才算闭环——否则它与"凭感觉看一眼"同级。

## 4. 边界：何时不可依赖 AI

按 [QUANT_SYSTEM_METHODOLOGY §6 人机边界](QUANT_SYSTEM_METHODOLOGY.md)：
**统计负责"排除"，判断负责"选择"**——统计说不显著，判断不能改口说"其实显著"，
只能降仓或不用。

AI **只可辅助、不可决策**的情形：

| 情形 | 兜底方式 |
|---|---|
| **指标要作为结论输出** | **A 闸**：`scripts/presentation_gate.py` 非零退出即阻断 |
| **代码/配置/文档改动** | **B 闸**：8 项清单逐项过 + 像攻击对手一样攻击自己的改动 |
| **🟢 / 升配 / 加仓 / 改阈值** | **C 闸**：双冻结 + 双跑 md5 一致 + **禁止取最好一轮** |
| **阈值/仓位变更后的文档** | **硬约束 2**：跑下方命令后**逐行判读**，确认无相反的无条件现状建议 |
| **结果无法运行、无法对照、无法抽检** | 默认按**不可信**处理 |
| **代码含密钥 / 依赖链未审计** | 安全评审后再合入 |

**硬约束 2 的命令**（放代码块，避免表格转义把它改坏）：

```bash
grep -nE "仓位|放大|可升至|≤[0-9]+%|净IR [0-9]" docs/DEPLOYMENT.md README.md
```

> 注意：`|` 写进表格单元必须转义成 `\|`，而转义后的字符串在 GNU ERE 中
> **不作析取**——实测 26 行 → 11 行，恰好漏掉「🟡 不得升配」那些关键行。
> **含 `|` 的 shell 命令一律放代码块，不进表格。**

## 5. 闭环：从直觉驱动到机制驱动

| 维度 | 直觉驱动（易受阻） | 机制驱动（可复现） |
|---|---|---|
| 判断依据 | "感觉这里不太对劲" | "第 3 行打印的变量类型与规范不符" |
| 验证时机 | 改完想起来才查 | **三道闸三个触发时机**，其中两个与"有没有改动"无关 |
| 调整方式 | 大面积随机修改 | **先写连带影响清单，每次只动一个变量** |
| 显著性 | 看行级 p 值 | **按 Fold 聚类**（行级 z=6.3 → p=0.167） |
| 通过标准 | 跑通了就行 | **预注册判据 + 双跑 md5 一致 + 禁止取最好一轮** |
| 沟通方式 | "再试一次" | "加日志，解释这一步的推导逻辑" |
| 结论落点 | 口头 / 散文 | **写入单一真相源 + 全库 grep 残留清零** |
| 最终效果 | 运气好能跑通，原因未知 | **可复现的过程与结论** |

> **确定性指过程与结论可复现，不是每次输出逐字相同**——LLM 本身仍是随机系统。

**五步闭环**：

```
① 命题前置   数据非空？分母是什么？连带改变了什么？    → 答不出就不开跑
② 预注册     看到结果前写下成功/失败判据               → 让猜错可判定
③ 隔离变量   连带影响清单 + 同配置双跑 md5             → 固定种子不够
④ 顺序验证   绝对值 → PBO → DSR → CI/lift → 才谈仓位   → 已知每级盲区
⑤ 落盘闭环   单一真相源 + 全库 grep 残留 + 文档逐行判读
```
