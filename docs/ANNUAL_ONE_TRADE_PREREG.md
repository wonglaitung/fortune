# 年度“一笔买卖”策略预注册

> **创建**：2026-11-13｜**状态**：跑前写死（未跑）
> **与 D114 的区别**：D114 是“按月份持有/空仓、可多次切换”；本实验是
> **每个自然年只做 1 笔（1 买 + 1 卖），年末空仓，次年重置**。
> **优化目标**：风险调整后收益（年化 IR / Sharpe），不是绝对收益。

## 0. 命题（可证伪）

- H0：用「历史最优 (买入月, 卖出月)」逐年滚动（扩张窗、天然 OOS）的
  年度“一笔买卖”策略，其**样本外风险调整收益不优于买入持有**（ΔSharpe ≤ 0）。
- H1：ΔSharpe **> 0**，且年度超额收益 95%CI 下界 **> 0**。

## 2. 规则（写死）

- 标的：**恒生指数 `^HSI`**，日收盘（F1 快照）。
- 每年：**当月第一个交易日买入**（入市月 M），**当月最后一个交易日卖出**（离开月 N），
  M ≤ N；**其余时间空仓**；年末必平仓，次年重新开始。全年**恰好 1 买 + 1 卖**。
- 执行：`daily_mark(..., lag=1)` T+1 生效。
- 成本：每笔往返 **0.2%**（指数 ETF，D97）。敏感性 0.5% 仅报告。
- 选择目标：**年度持有收益的 IR = mean/std**（年频，风险调整）。
- 程序 P（主假设）：每年末用**此前所有完整年度**（≥8 年）在 **78 个 (M,N)（M≤N）** 中
  选 IR 最高者，次年执行。首个可交易年 = 1996。

## 3. 窗口

- 主评估：1996-01-01 → 快照末日（31 年）。
- 子窗：2010 → 今。

## 4. 预登记判据（全部满足才算 H1 成立）

| # | 判据 | 阈值 |
|---|---|---|
| A1 | ΔSharpe = Sharpe(P) − Sharpe(买入持有)，同窗 | **> 0** |
| A2 | 年度超额（P − 买入持有）块 bootstrap 95%CI（block=3）下界 | **> 0** |
| A3 | maxDD(P) 浅于 maxDD(买入持有) **且** `has_timing_increment`（对照静态等仓位） | **是** |
| A4 | PBO（78 配对，CSCV S=8） | **< 0.5** |
| A5 | DSR（对 78 次试验去偏） | **≥ 0.95** |
| A6 | 2010→今 ΔSharpe | **> 0** |
| A7 | 相邻参数（固定最优格 M±1、N±1，9 格）ΔSharpe 符号一致 | **一致** |
| A8 | 双跑输出 md5 | **一致** |

- **MDE 同报**；**固定最优格仅描述（含选择偏差），不作判决**。

**失败判据**：A1–A8 任一不过 ⇒ 判 🔴/🟡，不部署、不再调买卖月。
**升配判据**：A1–A8 全过 ⇒ 才讨论；且受 D45 三报（适用范围/MDE/相邻参数）。
