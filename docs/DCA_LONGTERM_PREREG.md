# 定投恒指 + 长期持有 预注册

> **创建**：2026-11-13｜**状态**：跑前写死（未跑）
> **用户口径确认**：标的=恒指；有效性=“能赚钱”；每月固定金额；现金对照=存银行。

## 0. 命题（可证伪）

- H0：每月定投恒指、长期持有，**不能稳定赚钱/跑不赢存银行**。
- H1：每月定投恒指、长期持有，在 ≥10 年持有期**能赚钱**（期末 > 累计投入），且**多数窗口跑赢存银行**。

## 1. 三态前置

| 检查 | 结论 |
|---|---|
| 算不了？ | 否：2800.HK（含息）2008→今；^HSI（价格）1996→今；HIBOR 1996→今。 |
| 说不准？ | 部分：滚动窗口高度重叠，独立观测≈年数；仅报分布，不做伪显著检验。 |
| 先验已否？ | 否：定投是 beta/纪律型，不依赖 alpha；本项目 alpha 结论不直接否决它。 |

## 2. 规则（写死）

- **主口径（含息）**：`2800.HK`（盈富基金，追踪恒指）**前复权收盘**，2008-01→今。
- **保守下界（不含息）**：`^HSI` 价格指数，1996-07→今（`^HSI` 无分红，收益被低估）。
- **存银行**：HKD **1 个月 HIBOR**（`data/cnh_hibor/hibor_hkd.csv`），按月复利。
- **投入**：每月**第一个交易日**买入固定金额（金额无关，用 1 万示意）；按收盘价、可买小数份额。
- **成本**：每次买入 **0.1%**（ETF 佣金/价差），敏感性 0.25%。
- **持有**：投入后不卖，期末按收盘估值。
- **滚动窗口**：持有期 H ∈ {5,10,15,20} 年；每个起始月一个窗口。

## 3. 指标

- 期末资产 / 累计投入（倍数）、**定投年化 IRR**（资金加权，按月求解）、
- 同期**银行 IRR**（同投入、按 HIBOR 计息）、
- 窗口内**最差浮亏**（市值/累计投入 − 1 的最小值）——衡量“拿不拿得住”。

## 4. 预登记判据（**全部满足**才算“有效”）

| # | 判据（判定式） | 阈值 |
|---|---|---|
| K1 | ≥10 年窗口中，期末资产 > 累计投入 的占比（主口径 2800.HK；且 15 年同） | **100%** |
| K2 | ≥10 年窗口中，定投 IRR > 银行 IRR 的占比 | **≥ 75%** |
| K3 | 全期（首个可得月起投）定投 IRR > 银行 IRR | **> 0 差** |
| K4 | 保守下界（^HSI 不含息）≥10 年窗口 期末 > 投入 的占比 | **≥ 95%**（若 <，说明结论依赖分红，须注明） |
| K5 | 双跑输出 md5 | **一致** |

- `5 年`窗口与“最差浮亏”同报（诊断，不作通过条件）。
- 滚动窗口重叠 ⇒ 只描述分布，**不把“窗口占比”当独立显著性**。

**失败判据**：K1–K5 任一不过 ⇒ 判 🟡/🔴，不得宣称“定投恒指长期必赚”。
**升配/建议判据**：K1–K5 全过 ⇒ 才可写“长期定投恒指可赚钱”，并同报最差浮亏与 MDE 说明。
