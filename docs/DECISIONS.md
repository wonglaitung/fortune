## 一、一句话结论

> **港股个股"预测涨跌 → 选股"这条线的横截面 alpha 性价比已很低，停止投入；**
> 系统价值应转向 **恒指模型、异常检测、决策报告**；唯一保留的个股信号
> **`20d 行业中性 TopK`** 只作**低配辅助**、并**月度护栏监控**。

|---|------|-------------|
| D1 | **停止个股横截面 alpha 研发** | 完整管线 59 只 DSR 0.87 不过关（§5.11）；扩池后朴素因子稀释（§5.14）+ 简单模型学不到（§5.15，IC 转负） |

## 三、已验证 vs 已否定

| 命题 | 结论 |
|------|------|
| PIT 修正后个股绝对准确率≈随机（1d 50.8% 零经济价值、5d 51.8%、20d 51.6%） | ✅ 成立 |
| 横截面 Rank IC：5d 0.039–0.057、20d ~0.02（59 池） | ✅ 微弱但存在 |
| 20d 中性 TopK 扣成本后 IR ~0.7（全期）/ 1.52（2023–26） | ✅ 正但强度随口径 |
| 20d 中性 TopK 跨年度稳健（2021/2023 输、2022/2025/2026 胜） | ❌ 非每年胜 |
| 元标签"过滤提升 precision 到 75%"（业界示例） | ❌ 未复现，bootstrap 不显著 |
| 元标签"高波动减仓"因果 | ❌ 被 VolRule 对照证伪 |
| "扩池自动带来更强信号" | ❌ 只降噪，不增信号 |
| "Alpha158 因子 + 简单模型能学出 alpha" | ❌ IC 转负 |
| 银行高准确率=能力 | ❌ beta 陷阱（方向技能 −4.2pp） |
| **"异常大跌抄底"是真信号**（z≤−3 持 5 日，净IR 1.55，CI>0） | ✅ 显著，但**强依赖行情**（2021/2025 正、2023/24/26 负） |
| 恒指信号 Long/Flat 优于买入持有（1/5/20d） | ❌ 全部不优于（IR 0.11–0.13 vs 基准 0.38–0.49） |
| 恒指行情感知过滤能"救活"异常抄底（R1/R3 短期强势） | ❌ **短期强势有害**（IR 转负）；R2（恒指>MA200）提升整体 IR 1.55→2.40 但逐年仍依赖 2025 |
| 绝对阈值 0.60/0.65 能区分正常/弱震荡市场 | ❌ Isotonic 阶梯空转：两者通过率同为 **10.89%**（43,610 条回测）；须改分位门槛（D8） |

## 四、保留资产：`20d 行业中性 TopK` 策略规格（低配辅助）

| 参数 | 值 |
|------|-----|
| 池 | 现有 59 只（自选） |
| 信号 | CatBoost 20d `Predict_Prob`，**行业内 z-score** 后取 TopK=10 |
| 调仓 | 每 20 交易日非重叠，等权 |
| 成本 | 双边 0.5%（换手×成本逐期扣） |
| 护栏 | 月度复核：净IR≥0.7 且 PBO<0.5 且 DSR≥0.95 才可升配；否则降级/停用 |
| 仓位 | 辅助/倾斜，小仓位，单票上限、止损执行层控制 |
| 参考 | `ml_services/portfolio_backtest.py`、`eval_overfit.py`、`output/portfolio_20d_full12m.md` |

## 五、方法论护栏（每次改动必做）

1. 同折 walk-forward + **embargo=horizon**（已有）；
2. 指标：**横截面 Rank IC / ICIR + 扣成本净IR + lift + 方向技能**；
3. **block bootstrap CI**（点估计无效）+ **PBO(<0.5)** + **DSR(≥0.95)** + MinBTL；
4. **记录每次试验**，DSR 按真实试验次数收缩；
5. 禁：绝对准确率/胜率、事后删池、单年点估计、"月份×股票"极值。

## 六、停止做的事

- ❌ 个股"预测涨跌"二分类方向的调优（特征/模型/元标签）。
- ❌ 用绝对准确率/胜率排名选股/选板块。
- ❌ 事后剔除表现差的股票/板块。
- ❌ 在 59 只池上继续堆特征（收益已尽，见 §5.12）。

## 七、下一步（按价值排序）

1. **月度护栏自动化**：`20d 中性 TopK` + 恒指 + 异常检测，每月 PBO/DSR/lift 复核（本轮最有工程价值）。
2. **严格复核异常检测与恒指**（补成本+lift+bootstrap），一次性钉死"哪些是真信号"。
3. **数据源可靠性 + 扩历史（2018+）**：为任何"重启个股 alpha"留后门。
4. 若未来要重启个股：**更大池 × 完整管线（2054 特征 + LightGBM/DoubleEnsemble）**，先过 D1 的护栏再谈。
