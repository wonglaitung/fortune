> **依据**：2026-09 全轮实证（`docs/DECISIONS.md`、`docs/MODEL_IMPROVEMENT_PLAN.md` §5.x）

## 二、推荐架构

```
底仓 60-70%   恒生ETF（2800/2828），长期持有
战术1 5-10%   异常大跌抄底（恒指>MA200 才开）
战术2 ≤10%    20d 中性 TopK（月度护栏 🟢 才放大）
```

- **永不杠杆**；单票/单一信号设上限；每笔止损；
- 战术层总敞口 ≤ 20%，与底仓风险预算分离。

## 三、战术细则

### T1 异常大跌抄底（`ml_services/anomaly_dip_backtest.py`）

**开仓条件（全部满足）**
1. 个股当日收益 30 日 z-score ≤ **−3**（价格异常大跌）；
2. **恒指收盘 > MA200**（大盘长期上行）；
3. 排除 2023–24/26 类行情（按月复核，若该 regime 连续 2 个月负收益则暂停）。

**操作**：收盘买入，持有 **5 交易日**，到期平仓；单票 ≤5%、合计 ≤10%。
**风控**：每笔设止损（如 −6%）；**严禁用短期强势过滤**（恒指 20d/5d>0 已被证明有害）。
**预期**：牛市年份强（2025 类），磨底年份会亏；战术性质，非常开。

### T2 20d 行业中性 TopK（`ml_services/portfolio_backtest.py` + `monthly_guardrail.py`）

**学习器**：**LightGBM**（管线级 A/B 胜出：横截面 RankIC +0.032 vs CatBoost +0.023、护栏 🟢；
生产模型 `scripts/train_lightgbm_20d.py` 产出 `data/ml_trading_model_lightgbm_20d.pkl`，
`comprehensive_analysis.py` 优先加载）。最优组合参数：**top5-neutral**。

**开仓条件**
1. 每次 Walk-forward 后跑 `monthly_guardrail.py`；
2. **🟢 升级**（净IR≥0.7 且 PBO<0.5 且 DSR≥0.95）→ 可放大至 15–20%；
3. **🟡 保留**（当前）→ 仅 ≤10% 倾斜；
4. **🔴 停用**（IR≤0）→ 清仓。

**操作**：TopK=10、行业内 z-score、20 交易日非重叠调仓、等权、成本按 0.5%。

**仓位：元标签 Kelly（Isotonic 校准）**（`meta_labeling_ablation.py`，DECISIONS D6，§5.19）
- 用元模型输出 `P(主模型这笔会赢)`，**Isotonic 校准**后按 `0.5 × clip(2p−1, 0, 1)` 定每笔仓位；
- 实证（LightGBM 主模型，bootstrap 显著）：2025 ΔIR +0.35 [0.19,0.51]；全期校准后 +0.25 [0.10,0.40]；
- 过滤（硬阈值）**弃用**——它只会随机砍样本，不提升 precision；
- ⚠️ Kelly 只能放大/保护既有 edge，**不能把负 edge 转正**；主模型护栏 🟡/🔴 时同步收缩。

**风控**：单票上限、行业中性（不押单一板块）、调仓换手计入成本、Kelly 单笔上限（cap）。

### R 恒指方向信号（只读）
- 用于**判断 regime**：恒指 > MA200 才允许开风险战术；extreme_bear 全线停；
- **不作为独立交易信号**（实证 Long/Flat 不优于买入持有）。

## 四、风控与监控层（始终开）

| 层 | 工具 | 作用 |
|----|------|------|
| Regime 门 | 恒指 MA200 + 市场情绪层级 | 决定是否允许风险战术 |
| 报警 | `detect_stock_anomalies.py`（Z-Score/IF） | 盯异常个股，人工复核，不自动下单 |
| 决策 | LLM 综合分析报告 | 人机混合，最终裁决 |
| 复核 | `monthly_guardrail.py` | 每月：净IR/PBO/DSR/lift + 逐年 |

### 每日预测优化（用户视角，2026-09-25 落地）

`comprehensive_analysis.py`（16:00 HKT 每日）已集成的优化：

| 优化 | 做法 | 用户看到 |
|------|------|---------|
| **概率校准** | `ml_services/daily_confidence.py` 用历史拟合 Isotonic，把 probability 映射成真概率 | 报告里的"上涨概率"可信（20d 原始 0.8 → 实际约 0.54） |
| **置信度** | 每只股票加 `P(主模型判对)`（Isotonic 校准曲线），邮件显示 `(置信xx)` | 低置信建议一眼可见，不被不靠谱信号带偏 |
| **市场风险横幅** | 邮件顶部按 `market_layer` 给当日指引（🟢/🟡≥0.65/🟠≥0.70/🔴暂停买入），附上涨比例与动态阈值 | 开信即见"今天该不该买、买多紧"；极端熊市主动提醒收手 |
| **数据源可靠性** | `data_services/tencent_finance.py`：3 次重试 + yfinance 备用 + stock_cache/HSI 缓存兜底 | 网络抖动不再缺股票/缺数据，报告每天完整 |
| **20d 学习器** | LightGBM（§5.18） | 信号更强（RankIC +38%），护栏 🟢 |

> 校准器每次运行自动重拟合（`data/calibrators/*.pkl`，不入库）；校准/置信失败不影响原预测（try/except 兜底）。

### 监控报告解读示例（2026-09-24 实测）

`performance-monitor.yml`（00:00 HKT）生成的「诚实监控摘要 + 护栏状态」怎么读：

| 报告字段 | 实测值 | 正确解读 |
|---------|--------|---------|
| 准确率 | 54.4% | **不看**（会被趋势抬升） |
| 上涨占比（永远看涨） | 43.0% | 方向准确率的公平基准 |
| **方向技能** | **+11.4pp** | 方向判断确实优于"永远看涨"；但来自"会判跌"，**不等于买入能赚** |
| 信号净胜率（扣成本） | 42.5% | 买入信号仍 <50% |
| 无条件买入基准 | 37.9% | — |
| **超额 lift** | **+4.6pp** | 扣除行情后仅**微弱为正** → 边际，非强信号 |
| 20d 中性 TopK 护栏 | **🟡 保留低配** | 净IR 0.71 / PBO 0.30 / DSR 0.87，未达升级门槛（DECISIONS D2） |

**⚠️ 防误读**：
- 报告里**板块胜率**（如交易所 20d 70.6%）与**三周期模式**（011 探底回升 67.7%、101 假突破 67.4%）
  是**3 个月滚动、未 embargo、小样本**的实时统计，与 PIT 全期结论（模式≈随机，101=32%）矛盾，
  **不能当交易信号**；
- 整体口径：港股平均收益 **−0.70%**、夏普 **−0.09** → 系统**不靠方向预测赚钱**，
  实盘价值在 **底仓 beta + 战术（异常大跌抄底仅恒指>MA200）+ 护栏**。

## 六、复核与失败条件

**每月复核**（月度护栏 + 逐年）：
- `20d 中性 TopK`：净IR / PBO / DSR 逐月监控，判定见 DECISIONS D2；
- 异常抄底：逐年胜率/收益分布，若连续 2 个月在当前 regime 为负 → 暂停。

**复核怎么执行（两种用法）**：

| 场景 | 做法 |
|------|------|
| 模型/特征/数据有改动 | 调用 **模型验证技能 `/model_validation`**（SOP 全流程：walk-forward → 阶段 5.5 严谨评估 → **阶段 5.6 月度护栏判定** → 文档/提交）。⚠️ walk-forward 本身约 3h |
| 仅需对已有最新预测复核 | 直接 `python3 ml_services/monthly_guardrail.py --horizon 20`，提交 `output/monthly_guardrail_*.md`（秒级，不重训） |

> 日常节奏：有改动 → `/model_validation` 全流程；无改动 → 直接 `monthly_guardrail.py`。
> 结果 md 提交后，`performance-monitor.yml` 的邮件会自动带上护栏判定（"策略护栏状态"节）。

**失败/收缩条件**：
- 恒指 < MA200 且情绪 extreme_bear → 战术层清零，仅留底仓/现金；
- 任一战术 DSR 持续 <0.9 或 IR≤0 两个季度 → 停用；
- 出现数据源中断/特征口径变化 → 暂停自动调仓，人工复核。

**重新放开**：
- 只有"更大池 × 完整管线 × 更长历史"且重新通过 D3/D5 护栏（`docs/DECISIONS.md`）后才考虑重启个股 alpha。

## 七、诚实预期

> 系统当前的价值是**控制风险与决策纪律**，不是稳定的超额收益：
> 底仓吃 beta，战术只在少数高胜率窗口小仓参与；任何战术都可能多年无效。
> **实盘首要目标：活下来 + 不因 alpha 幻觉亏钱**；超额是加分项，不是承诺。
