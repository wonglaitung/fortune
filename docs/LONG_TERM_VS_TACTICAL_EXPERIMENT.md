## 1. 命题

- **H0（主）**：底仓组合**成本后**相对**310 池等权**的年化超额 ≤ 0。
- **H1（主）**：底仓组合成本后年化超额 > 0，且 95%CI 下界 > 0。
- **H0'（相对）**：底仓的超额 IR ≤ 战术层 20d Top10 的超额 IR **+0.05**（BASELINES B2 实测值）。
- **H1'（相对）**：底仓超额 IR ≥ **1.05**（= 0.05 + 1.0，1.0 为功效保守垫）。

## 2. 口径（全部写死）

### 2.1 宇宙与可投资性（调仓日 T）
- 池：**当前 310 池**（`data/hk_broad/universe_310.json`）⇒ **幸存者偏差，声明**。
- 需满足：① T 日有前复权价格；② 至少 5 个完整财年的年报且**披露日 ≤ T**（见 2.2）；③ 过去 20 日中位成交额 ≥ **5000 万 HKD**（摩擦成本门槛，B12 最低分位往返 2.06%）。

### 2.2 PIT 规则（**防前视**）
- 财报可用日 = **财年结束日 + 120 天**（保守；港股年报多在 3 个月内出）。
- 调仓日 T 只能用**披露日 ≤ T** 的财年数据；价格用 T 日收盘（前复权，近似总回报）。
- 敏感性：滞后 **90 / 120 / 180 天**。

### 2.3 选股规则（只用 T 之前数据）
硬过滤：① 5 年无亏损年；② 非金融 OCF÷净利 3 年均值 ≥ 0.9；③ 资产负债率 ≤ 70%；④ 最差单年利润跌幅 > −30%；⑤ 金融股：ROE ≥ 8%、股息率 ≥ 3%。
排序打分（z 分截面，**全池同刻**）：
```
score = 0.30·z(ROE3) + 0.15·z(净利CAGR3) + 0.15·z(营收CAGR3)
      + 0.10·z(OCF÷净利) + 0.15·z(−PE) + 0.15·z(股息率+净回购收益率)
```
（PE 用 T 日价 ÷ 最近已披露财年 EPS；币种按 `scripts/screen_longterm_core.py` 规则：内地 CNY×1.08，港资/英美 HKD×1.0。）

### 2.4 组合构造
- 持仓 **N=20 等权**；缓冲区：持有股跌出前 **2N=40** 名才卖（降换手）。
- 调仓频率：**季度**（3/6/9/12 月首个交易日）。
- 相邻参数网格（**须全报，不许只报最好一格**）：
  - 频率：季度 / 半年 / 年度
  - N：15 / 20 / 30
  - 披露滞后：90 / 120 / 180 天

### 2.5 成本
- 换手口径：`0.5 × Σ|Δw| × 往返成本`（项目标准，`ml_services/costs.py`）。
- 往返成本主口径 **flat 1.02%**（310 池实测隐含，B12）；敏感性 **0.58%**（30 只口径）与 **2.06%**（低流动性五分位中位）。

### 2.6 基准（**双基准，防"只是 beta"**）
1. **310 池等权**（每季调仓、**不计成本**）——主基准，检验"选股 alpha"。
2. **HSI**（腾讯 `hkHSI` 日线）——绝对表现参照。

### 2.7 对照（防"只是少投/择时"，G5）
- **静态等权 310 池买入持有**（不调仓、无成本）。
- 若底仓与静态等权无差异 ⇒ 价值只来自"少交易"，不是选股。

### 2.8 窗口
- **主窗**：2023-06-01 → 2026-09-30（与战术层 B2 同窗）。
- **独立窗**：2016-01-01 → 2023-05-31（先验外推窗）。
- 两窗须**同号**才算稳。

### 2.9 统计口径
- 月度**超额**序列（组合 − 等权基准 − 成本）→ 净 IR、年化超额、95%CI（Newey-West t）。
- **MDE** 必报（IR 单位）；**逐年**超额必报。
- 回撤：**逐日 mark-to-market**（不用稀疏期净值）。
- 终值 **IRR** 与终值同时报（不只报终值）。
- 闸：A 闸（绝对值异常）、PBO < 0.5、DSR ≥ 0.95、净 IR CI 下界 > 0。
