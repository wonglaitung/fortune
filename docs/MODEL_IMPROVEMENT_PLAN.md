**关键推论**：第 1 层的瓶颈是**选股强度**（港股独有劣势）；第 3 层的瓶颈是**择时形式本身**
（A股 同样中招，p=0.73/0.65）→ 「A股有优势」止步于第 1 层，不延伸到可交易性。

- PIT：收市后次日凌晨发布 → 用 T-1，天然时点安全；三冻结按日逐日落盘即可
- 横截面属性：✅ 逐股 → 直接横截面特征，不必交叉

**② 分析师修正 / 盈利惊喜 —— 可行性 ★★（难在 PIT 与免费历史）**
- 付费金标准：Refinitiv I/B/E/S（LSEG，覆盖港股）、FactSet、Bloomberg → 贵，机构级

- 横截面属性：✅ 逐股 → 直接横截面
- 最大坑：PIT 必须用「修正发生日」而非「最新共识」，否则穿越；季度稀疏、小盘覆盖少

**③ 美元/CNH、HIBOR —— 可行性 ★★（市场级，须交叉）**

- PIT：每日定盘，T-1 安全；三冻结易
- 横截面属性：✗ 市场级（全市场同值）→ 按纪律必须与个股特征交叉才有用
