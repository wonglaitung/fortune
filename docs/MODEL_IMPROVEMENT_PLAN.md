```

            → 不开跑
 ② 执行中   §2.1 连带影响清单没写 ／ 一轮改了 ≥2 个量 ／ §2.2 未清缓存双跑或 md5 不一致
            → 不开跑；不复现即 bug
 ③ 出结果   §3.1 判读顺序  绝对值异常 → PBO → DSR → CI/lift → 仓位
            → 前一级不过，后一级不看，该级结论不作数
 ④ 呈现前   A 闸 `python3 scripts/presentation_gate.py --input <csv> --horizon N`
            非零退出 → 阻断
 ⑤ 提交前   B 闸 8 项清单（[REVIEW_GATES.md](REVIEW_GATES.md)）任一不过 → 重审
 ⑥ 升级前   C 闸 未双冻结 ／ 双跑 md5 不一致 ／ 取了最好一轮 → 阻断
 ⑦ 收尾     §6 未落盘 ／ §8 检查表未逐项打勾 → 没有落盘 = 没有做
```

**六条最高频违规，FAIL 判定式**（开跑前与收尾时各自查一遍）：

| # | 硬规则 | FAIL 判定式 → 后果 | 指针 |
|---|--------|-------------------|------|
| 1 | 预注册优先于结果 | 判据在看到结果之后才写或改 → **本轮作废** | §1.2 |

| 4 | 行级统计不作因果 | 用行级 z/p 下「因为 X 所以 Y」且无折聚类检验 → **结论作废** | §1.1 |
| 5 | 空数据不证伪 | 行数 0 ／ 唯一值 1 ／ `n_eff<30` 却判「无信号」→ **结论作废** | §1.1 |
| 6 | 门槛与分母分开 | 「表现如何」与「样本够不够」混为一谈 → **判定作废** | §1.1 |

## 1. 三层拆解

```
┌────────────────────┬──────────────────┬──────────────────────────┐
│ 第1层 选股(横截面)  │ 第2层 择时(时序) │ 第3层 可交易(组合层)      │
├────────────────────┼──────────────────┼──────────────────────────┤
│ IC +0.045 p=0.108  │ IC +0.218        │ 择时 vs 买入持有          │
│ ❌ 不显著           │ p<0.0001 ✅      │ 港股 同窗.066/.095        │
│ 解除条件 ≥+0.10    │ 信号已显著        │      全窗.12/.15          │
│      & p<0.05      │ 问题不在这层      │ A股  .73/.65             │
│ 差 2.2× / p=.097   │                  │ ❌ 全部 >0.05             │
├────────────────────┼──────────────────┼──────────────────────────┤
│ 卡在【强度】       │ 卡在【能不能     │ 卡在【形式本身】          │
│                    │  变成收益】      │ = 全局瓶颈，两地共同      │
│ H1-A 扩池          │ H2-A 事件型信号  │ H3-A 成本口径             │
│ H1-B 延长历史 ←优先│      (D4 已证明) │ H3-B 降换手               │
│ H1-C 相对标签      │ H2-B 第二个信号  │ H3-C 挑 TopK              │
│ H1-D 特征/模型     │                  │ H3-D 连续仓位 ←未试       │
│   └─ A/C/D 均关闭  │   └─ 逐年不稳    │   └─ B/C 均已试且有害      │
└────────────────────┴──────────────────┴──────────────────────────┘
```

**关键推论**：第 1 层的瓶颈是**选股强度**（港股独有劣势）；第 3 层的瓶颈是**择时形式本身**
（A股 同样中招，p=0.73/0.65）→ 「A股有优势」止步于第 1 层，不延伸到可交易性。
