## 3. 置换检验：最优/最差配对是否超出纯噪声

- 名义最优：**1月入市 → 12月离开**，均值 **+9.85%**；置换检验 p=0.659（2000 次）。
- 名义最差：**8月入市 → 8月离开**，均值 **-1.54%**；置换检验 p=0.323。
- 零分布参考：纯噪声下 66 个配对的「最优」均值分布 95 分位 = +12.20%；「最差」5 分位 = -2.69%。
- ⇒ **最优配对未超出噪声**（p>0.05）：不能据此断言「某月入某月出」更好。
- Bonferroni(66) 对照：α = 0.05/66 = 0.00076（单配对 t 检验几乎不可能通过）。
- **风险调整口径**：IR 最优 1.26 的置换 p=0.552；IR 最差 -0.96 的置换 p=0.053。

## 6. 结论（条件化）

**入市（相对低点）**：按平均季节路径 —— 全样本谷在 1月；2000 年后谷在 3月；2010 年后谷在 9月；2015 年后谷在 10月。
**离开（相对高点）**：按平均季节路径 —— 全样本峰在 12月；2000 年后峰在 12月；2010 年后峰在 4月；2015 年后峰在 4月。
**风险调整后最强的单月持有**（对角线 IR）：全样本 7月(IR 1.26)；2000 年后 4月(IR 1.41)；2010 年后 4月(IR 1.43)；2015 年后 4月(IR 1.45)。
**最弱的单月**：全样本 8月(IR -0.96)；2000 年后 3月(IR -0.92)；2010 年后 8月(IR -1.35)；2015 年后 8月(IR -0.97)。
- **统计强度**：66 个配对里挑出的最优在置换检验下 未超出噪声（p>0.05）；因此「某月入、某月出」只能当弱先验，不能当规则。
- **与单月表一致**：强的单月是 2/4/7/12 月，弱的单月是 3/8 月；但均未过 Bonferroni。
- **落地边界**：任何「按月择时」规则须预注册 + 三冻结 + 双跑 md5；本报告为描述性，MDE≈5%/半年量级，小效应测不出。
