# 季节性择时（逐月入市/离开）预注册

> **创建**：2026-11-13｜**状态**：跑前写死（未跑）
> **前置**：`docs/MONTH_ENTRY_EXIT.md` 已给出**描述性**结论（66 配对置换检验均未超出噪声）。
> 本实验不是"再挑一次最好"，而是检验**程序是否具备样本外价值**。

## 0. 命题（可证伪）

**主假设（程序 OOS，唯一判决对象）**
- H0：用「历史最优月份配对」选出的季节规则，其**样本外净超额年化 ≤ 0**。
- H1：样本外净超额年化 **> 0**，且块 bootstrap 95%CI 下界 **> 0**。

**次假设（固定规则，仅描述，不作判决）**
- R1「11–4 月持有、5–10 月空仓」——该规则**由已看过的数据选出，含选择偏差**，
  只作参照，**不得因其好看而推翻主假设的失败**。

## 1. 三态前置（任一命中即停）

| 检查 | 结论 |
|---|---|
| 算不了？（缺数据/无 PIT） | **否**：恒指日线 1987→今；日历规则无前视。 |
| 说不准？（功效不足） | **部分**：n≈30–39 年，半年尺度 MDE≈5%；只能检出较大效应。 |
| 先验已否？（已有强反证） | **是**：`MONTH_ENTRY_EXIT.md` 置换检验 p>0.5；`YEAR_START_RALLY.md` 亦 null。 |

⇒ 先验为负。本实验的**增量信息**来自主假设（程序 OOS），不是重复挑格。**若主假设亦 null ⇒ 停止在日历维度继续搜。**

## 2. 规则（写死）

- 标的：**恒生指数 `^HSI`**，日收盘。
- 执行：信号只用**日历日期**（无前视）；`daily_mark(..., lag=1)` **T+1 生效**。
- 成本：**往返 0.2%**（指数 ETF，无印花税，D97 同 `classic_timing_backtest`）。敏感性 0.5% 仅报告。
- 空仓收益：**0**（不计无风险利率，保守拖延）。
- 固定规则 R1：持仓月 = {11,12,1,2,3,4}，其余空仓。
- 程序 P（主假设）：在每个**年度末**，用**此前所有完整年度**，在 66 个 (入市月,离开月)、
  入市≤离开 的配对中，选**历史均值最高**者；下一年按该配对持有（当月第一个交易日起、离开月最后一个交易日止），
  其余空仓。需 ≥8 年历史才开始（首个可交易年 = 1996）。**逐年滚动 = 天然 OOS。**

## 3. 窗口

- 主评估：**1996-01-01 → 快照末日**（程序 P 的 OOS 全程）。
- 子窗：2005→今、2010→今（独立窗检查）。

## 4. 预登记判据（**全部满足**才算主假设成立）

| # | 判据（判定式） | 阈值 |
|---|---|---|
| P1 | 程序 P 净 CAGR − 买入持有净 CAGR（同窗） | **> 0** |
| P2 | 年度超额（P − 买入持有）块 bootstrap 95%CI（block=3）下界 | **> 0** |
| P3 | maxDD(P) 浅于 maxDD(买入持有) **且** `has_timing_increment`（对照静态等仓位） | **是** |
| P4 | Sharpe(P) | **≥ Sharpe(买入持有) − 0.05** |
| P5 | PBO（66 配对，CSCV S=8） | **< 0.5** |
| P6 | DSR（对 66 次试验去偏） | **≥ 0.95** |
| P7 | 2010→今 子窗净超额 CAGR | **> 0** |
| P8 | 双跑输出 md5 | **一致** |

- **MDE 同报**：年度超额均值的最小可探测效应（t×std/√n）。
- **相邻参数**（仅诊断，不作通过条件）：R1 入市月 ±1、离开月 ±1（9 格）净超额符号是否一致。

**失败判据**：P1–P8 任一不过 ⇒ 判 🔴/🟡，**不部署、不再调月份**。
**升配判据**：P1–P8 全过 ⇒ 才讨论是否把季节层纳入风控/仓位，且仍受 D45 三报（适用范围/MDE/相邻参数）约束。
