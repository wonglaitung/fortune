## 二、时间关系分析 ⏰

### 2.1 持有期结构

```
时间轴: T(预测日) ---- T+1 ---- T+5 ---- T+20
         │          │        │        │
1天周期:  [━━━━━━━━] 持有期[T, T+1]
5天周期:  [━━━━━━━━━━━━━━━━━] 持有期[T, T+5]
20天周期: [━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━] 持有期[T, T+20]
```

**关键发现**:
- 1天持有期完全包含在5天周期内（前20%时段）
- 1天持有期完全包含在20天周期内（前5%时段）
- 5天持有期完全包含在20天周期内（前25%时段）

### 2.2 时间层级关系

| 关系 | 描述 | 影响 |
|------|------|------|
| **短→长包含** | 短周期是长周期的"快照" | 1天表现影响5天，5天影响20天 |
| **累积效应** | 长周期是短周期的累积 | 20天收益 = 4个5天 ≈ 20个1天 |
| **噪音过滤** | 周期越长，噪音越少 | 1天噪音最大，20天趋势最清晰 |

## 三、因果关系分析 🔗

### 3.1 预测正确性的传导效应

**PIT/embargo 验证结果**（697个样本）：

| 条件 | 准确率 | 说明 |
|------|--------|------|
| 1天预测正确时 → 20天也正确 | 58.12% | 传导弱 |
| 1天预测错误时 → 20天正确 | 56.83% | 基准水平 |
| 5天预测正确时 → 20天也正确 | 61.87% | 传导较弱 |
| 1天+5天都正确时 → 20天也正确 | 64.81% | 双重确认（略好） |

**核心发现**：
- 20天独立准确率 57.53%；1天/5天正确带来的提升有限（+1.3pp ~ +7.3pp）
- 传导效应存在但远弱于此前报告
- **传导效应存在但较弱**：短期正确对长期准确率有正向影响

**指标含义说明**：
- **"1天预测正确时 → 20天也正确"**：当1天预测方向正确时，20天预测也正确的概率
- **"1天+5天都正确时 → 20天也正确"**：当1天和5天预测方向都正确时，20天预测也正确的概率
- 这是**预测正确率的传导**，不是预测概率与实际方向的相关性

### 3.2 预测概率与实际方向的相关性

| 相关性 | 数值 | 解读 |
|--------|------|------|
| 1天预测概率 与 5天实际方向 r | **+0.17** | 正相关 |
| 5天预测概率 与 20天实际方向 r | **+0.33** | 正相关（较强） |
| 1天预测概率 与 20天实际方向 r | **+0.12** | 正相关 |

**指标含义说明**：
- **"5天预测概率 与 20天实际方向 相关性 r"**：5天模型预测上涨的概率值（0-1）与20天实际涨跌方向（涨=1，跌=0）的相关系数
- **r > 0（正向）**：预测概率越高，实际上涨概率也越高 → 顺势操作有效
- **恒指 r = +0.35**：预测概率与实际方向正相关，顺势操作有效

**结论**：经 PIT/embargo 验证，八大模式准确率均接近随机（30%–58%），**不构成可靠交易信号**。此前"假突破最优"等结论来自无 embargo 的边界泄漏。

**因果解释**:
```
T日    T+1日  T+5日  T+20日
 │      │      │      │
 ├─短线假突破─┤      │
        │           │
        └─→ 真趋势向上 ←─┤
                      │
                   实际: 涨（32.26%准确）
```

- 短期(1天): 假突破信号，模型识别为涨
- 中期(5天): 修正判断，识别为跌
- 长期(20天): 真实趋势向上
- 实际: 短线假突破后，长期趋势确立

**交易启示**:
> 当出现"短线看涨但中线看跌"信号时，如果长周期看涨，**相信长周期**，这是"假突破抄底"信号！
