## 1. 命题（M1）

**A-H 溢价对每对股票自身历史做时序均值回归**：溢价偏高 → 未来该对 H 腿相对走弱；溢价偏低 → 未来走强。

**为什么值得试**：D1 的止投理由是港股**有效独立横截面仅 ~3–4**（beta 共动）。M1 用**跨市场相对定价**做信号，横截面在「溢价」这一**相对维度**上重建，不依赖港股自身的 beta 分散度 → 这是唯一绕开共动天花板的候选。

**可交易形态（受审计约束锁定）**：
- **不能做多H/空A**：A 股散户融券实质不可得 → 只做 **H 腿多头倾斜**（溢价低→加 H，溢价高→减 H）。
- **不是无风险套利**：资本管制下 A/H 不可自由互换，溢价结构性存在（均值 0.93–2.28）→ 慢速相对价值。
- 系统为播报无执行 → 结论为**纸面组合净 IR**，同 D2 口径。

## 2. 数据（已落盘，零成本抓取已完成）

`/tmp/opencode/ah/data/`：13 对 A+H（工/招/建/平/寿/神/太/农/长/亚/电/移/油），qfq 同源。

- 溢价定义（PIT 严格）：`premium_pit_t = 1 / ((H_hkd_t / A_cny_t) × FX_{t-1})`，FX = HKD/CNY。
- **⚠️ FX 滞后 1 日是强制项**：实测同日 FX 日线收盘于 ~22:00 UTC，晚于 A(07:00)/H(08:00) 收盘 → 同日 FX 是未来函数（相对偏差仅 0.27%，但方向错，按纪律一律 t-1）。
- 日历：双方同日重叠 96.9%，inner-join 后为共同交易日。

## 3. 形态与信号（单变量，跑前锁定）

- **频率**：月频（每月末 1 个调仓日），换手低，契合港股 ~9%/年摩擦。
- **信号**：对每对，`z_t = (premium_pit_t − mean(premium_{t−12m..t−1})) / std(同窗)`（12 个月滚动、仅用 t−1 及更早 → PIT）。
- **持有**：`s_t = −sign(z_t)`（溢价高→减/空 H 腿，溢价低→多 H），下月实现。
- **标的**：13 对全部（短窗 3 对电/移/油 A 股 2021–22 才 IPO，单独标注，**不与长窗混算主判据**，仅作稳健性附录）。
- **对照组**：买入持有 H（等权 13 对）、买入持有 A。

## 4. 判据（看到结果前写死）

**主判据（D2 三门槛 + 相对基准）**：
1. **净 IR ≥ 0.7**（成本后，月频 H 腿组合 vs 等权买入持有 H）**且 bootstrap 95% CI 下界 > 0**；
2. **PBO < 0.5**（topk∈{5,10,全部}×{raw,相对} 六配置族，`eval_overfit.build_matrix`）；
3. **DSR ≥ 0.95**（同 `monthly_guardrail` 口径）。

**分位/幅度辅助判**（任一不过即降档，不单独作结论）：
- 相对基准的**折聚类 lift > 0 且 p<0.05**；
- 月频相对净收益均值 > 0。

**判定式**：
- 三门槛全过 → 🟢 可提至低配辅助（同 D2「净IR≥0.7 且 PBO<0.5 且 DSR≥0.95」）；
- 仅 IR>0 或 CI 跨 0 → 🟡 低配/记账；
- 净 IR ≤ 0 → 🔴 关闭，**一发制，不调参、不换形态重跑**。

**成本**：H 腿双边 0.5%（沿用项目 `COST=0.005` 口径），A 腿仅作信号不交易故不计成本。

**显著性口径**：一律**月频折/期聚类**，禁行级 z（lessons 三.29）。
